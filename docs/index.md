# BiMaUmisc: BiMaU Miscellaneous ![](reference/figures/hex.png)

Contains a function to plot publication-ready survival curves using the
[Kaplan-Meier method](https://doi.org/10.2307/2281868) (1958), a
function to format *p*-values, and a function to automatically select
statistical tests for comparing continuous variables between groups,
which are useful for repetitive analyses.

BiMaU stands for the Biostatistics and Mathematics Research Unit at the
Sant Joan de Déu - Pediatric Cancer Center Barcelona. Our unit is
responsible for carrying out the statistical analyses for the paediatric
cancer research group.

## Installation

The `BiMaUmisc` package can be installed from
[CRAN](https://cran.r-project.org/):

``` r
install.packages("BiMaUmisc")
```

To install the GitHub version:

``` r
# install.packages("remotes")
remotes::install_github("BiMaU-PCCB/BiMaUmisc")
```
